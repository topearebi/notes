## 2.1 Language Typology (The "Lego vs. Clay" Audit)
**Order of Implementation:** 1. Identify the morphological classification of your target language. 
2. Determine if it is Head-Initial or Head-Final. 
3. Check for Pro-Drop (can pronouns be omitted?). 
4. Log these meta-rules to calibrate your expectations before you start translating sentences.

**Suggested Sources:** WALS (World Atlas of Language Structures) Online, Wikipedia's "[Language] Grammar" pages, basic linguistic overview videos.

### Template: The Typology Audit
| Parameter | Classification | What this means for your learning load | Example (Target Language) |
| :--- | :--- | :--- | :--- |
| **Morphology** | Agglutinative ("Sticky") | Words will get very long. Focus on identifying the root word vs. the stacked suffixes. | **Japanese:** *Tabesaserareta* (was made to eat). |
| **Head-Direction** | Head-Final | The most important information (the verb) comes at the absolute end of the sentence. | **Japanese:** I apple ate. |
| **Pro-Drop** | Yes | Do not memorize "I/You/He" as strictly as in English. Focus on verb endings which carry that data. | **Spanish:** *(Yo)* como manzanas -> *Como manzanas*. |
| **Case/Gender** | Case (Noun changes) | Nouns will change spelling depending on if they are the subject or object. | **German:** *Der Hund* (subject) vs *Den Hund* (object). |

## 2.2 The Syntax Highway & The Romanization Bridge
**Order of Implementation:** 1. Identify the default word order sequence. 
2. Identify how questions and negations are formed. 
3. *Crucial:* Write all findings in a Romanized/Phonetic script. Do not attempt to read the native script while verifying syntax.

**Suggested Sources:** Introductory grammar websites (e.g., Tae Kim’s Guide to Learning Japanese, SpanishDict), basic translation tools.

### Template: The Default Sequence Map
| Concept | L1 (English) Rule | Target Language Rule | Romanized Example |
| :--- | :--- | :--- | :--- |
| **Default Order** | Subject-Verb-Object (SVO) | Subject-Object-Verb (SOV) | *Watashi wa ringo o taberu.* (I apple eat) |
| **Adjectives** | Adjective + Noun | Noun + Adjective | *El coche azul.* (The car blue) |
| **Negation** | Subject + Do Not + Verb | Subject + No + Verb | *Yo no fumo.* (I not smoke) |
| **Questions** | Do/Does/Is + Subject + Verb? | SVO + Question Particle | *Nǐ hǎo ma?* (You good [question particle]?) |

## 2.3 The Golden 13: "Unit Testing"
**Order of Implementation:** 1. Take the 13 English diagnostic sentences. 
2. Run them through a highly accurate translator or ask a native speaker to translate them naturally. 
3. Deconstruct the translation using your Romanization Bridge to uncover the hidden OS rules. 

**Suggested Sources:** DeepL Translator, ChatGPT (prompted to break down the grammar logic of the translation), HelloTalk or Tandem for native speaker verification.

### Template: The Golden 13 Unit Test (Excerpt)
| ID | Concept (English) | Target Translation (Romanized) | Logic Note (The "Why") |
| :--- | :--- | :--- | :--- |
| **G1** | The apple is red. | *La manzana es roja.* (Spanish) | Uses "to be" (*es*). Adjective matches the feminine noun (*roja*). |
| **G2** | John's book. | *El libro de John.* (Spanish) | No possessive 's. Uses "The book of John." |
| **G3** | I ate the apple. | *Kabe apple yā.* (Mandarin - *Wǒ chī le píngguǒ*) | Verb (*chī*) doesn't change. Adds completion particle (*le*) after verb. |
| **G5** | I am not eating. | *Je ne mange pas.* (French) | Negation surrounds the verb: *ne* + verb + *pas*. |
| **G6** | There is a dog. | *Hay un perro.* (Spanish) | Uses a specific existential verb (*Hay*) instead of "There is". |

## 2.4 The Functional "Glue" (Logical Connectors)
**Order of Implementation:** 1. Search for the specific high-frequency operators that link concepts together. 
2. Note if these operators force the rest of the sentence to change its word order (e.g., German verb-kicking).

**Suggested Sources:** Frequency dictionaries (looking specifically for conjunctions and prepositions), Clozemaster.

### Template: The Operator Matrix
| Category | English Concept | Target Language Connector | Structural Quirk / Rule |
| :--- | :--- | :--- | :--- |
| **Causal** | Because / Therefore | *Weil* (German) | "Kicks" the conjugated verb to the very end of the sentence. |
| **Contrast** | But / However | *Pero* (Spanish) | Placed at the start of the contrasting clause. No structural change. |
| **Relational** | In / On / At | *Ni* (Japanese) | It is a **post**position. It goes *after* the noun: *Tokyo ni* (In Tokyo). |
| **Temporal** | Before / After | *Yǐqián* (Mandarin) | Placed *after* the event: [Event] + *yǐqián* (Before [Event]). |

## 2.5 Parallel Track: Script Anatomy
**Order of Implementation:** 1. Separate this entirely from Sections 2.1–2.4. Dedicate 10-15 minutes a day strictly to script decoding.
2. Learn the stroke order rules (Ductus). 
3. Identify the core visual building blocks (Radicals/Roots) rather than memorizing complex characters by rote.

**Suggested Sources:** Outlier Linguistics (for Hanzi/Kanji), Omniglot.com (for writing system mechanics), Skritter (app for stroke order).

### Template: The Script Deconstruction Log
| Feature | Target Script Logic | Actionable Practice Step | Example |
| :--- | :--- | :--- | :--- |
| **Mechanical (Ductus)** | Left-to-Right, Top-to-Bottom. | Practice drawing the 5 basic stroke types before attempting full characters. | **Hanzi:** Draw horizontal lines before vertical intersecting lines. |
| **Semantic (Radicals)** | Characters are built from meaning-components. | Memorize the "Big 20" Radicals (Water, Fire, Person, Tree, etc.) as standalone visual units. | **Hanzi:** 氵 (Water radical) -> frequently appears in words like river, sea, wash. |
| **Composition Logic** | Syllable Blocks. | Practice stacking consonant-vowel-consonant combinations into uniform squares. | **Hangul:** ㅎ (h) + ㅏ (a) + ㄴ (n) = 한 (han). |
