### Account Recovery Procedures
> **Important:** Vaultwarden operates on a zero-knowledge principle. The server never stores a user's master password, and therefore an administrator **cannot** reset a password to recover an existing encrypted vault. The following procedures must be used instead.
#### **1. Recommended Method: Emergency Access (Proactive)**
This is the primary and safest method for account recovery and must be configured proactively. It allows a trusted user (the Grantee) to request access to another user's vault (the Grantor).
* **System Policy:** The `Tope/Admin` account is to be configured as the designated emergency contact for all other user accounts on the server (e.g., `Oyinda`, `Adun`).
* **User Setup Process:**
    1.  Log in to Vaultwarden.
    2.  Navigate to **Account Settings -> Emergency Access**.
    3.  Invite the designated emergency contact (`Tope/Admin`) via their email address.
    4.  Set the desired level of access (View or Takeover).
    5.  Define a wait time (e.g., 7 days) before access is granted, giving the original user time to reject a request.
#### **2. Administrator Method (Last Resort)**
This method should only be used if Emergency Access was not configured and a user is permanently locked out. **This process will result in the complete deletion of the user's vault data.**
* **Process Flow:**
    1.  The administrator (`Tope/Admin`) logs into the Vaultwarden admin panel at `https://vault.topearebi.xyz/admin`.
    2.  The locked-out user's account is located and **deleted**.
    3.  The user can now re-register for a new account using the same email address.
    4.  The new account will have a fresh, **empty vault**. The user can restore their data only if they have a personal, unencrypted backup file to import.
