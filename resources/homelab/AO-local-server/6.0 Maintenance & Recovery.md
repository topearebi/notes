## 6.2 System & Docker Maintenance
### Container update process
Container updates are handled automatically by Watchtower. This service polls for new base images for all running containers and redeploys them if an update is available.

- **Notifications:** A notification is sent to a dedicated Discord channel upon a successful update.
- **Mechanism:** The notification is dispatched via an Apprise service, which is configured within Watchtower's environment variables. The Apprise webhook URL is stored as a secret in `[Placeholder for location of secret, e.g., the .env file for the Core Utilities stack]`.
### Routine Maintenance Commands
To prevent the accumulation of unused Docker objects and to reclaim disk space, a periodic manual clean-up should be performed. These commands will not affect running services.
#### 1. Check Disk Usage
To see a summary of Docker's current disk usage, run the following command:
Bash
```
docker system df
```
### 2. Perform Standard Clean-up
This command removes all stopped containers, dangling images, and unused networks. It is the safest and most common clean-up command.
Bash
```
docker system prune
```
You will be asked to confirm; type `y` and press Enter.
#### 3. Clean Up Unused Volumes
This command removes any Docker-managed named volumes that are not currently attached to a container. **This command will not affect any of the bind-mounted data in `C:\server\`**, so it is safe to run.
Bash
```
docker volume prune
```
