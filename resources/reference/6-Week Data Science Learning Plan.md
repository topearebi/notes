# 6-Week Data Science Learning Plan

Here's a comprehensive 6-week schedule designed for aspiring data analysts, aiming to equip them with foundational knowledge and practical skills in SQL, DAX, and Power BI. This schedule is optimized for a 1-hour daily commitment and incorporates hands-on tasks, projects, and portfolio-building activities.

**Week 1: Introduction to SQL**

- **Day 1:** What is SQL? Basic syntax, SELECT statement, filtering with WHERE clause.
    - **Task:** Write queries to retrieve specific data from a sample database (e.g., customer names, orders within a date range).
- **Day 2:** Working with Operators (AND, OR, NOT, IN), sorting data with ORDER BY.
    - **Task:** Query the sample database to find customers who meet multiple criteria (e.g., live in a certain city AND have made an order over a certain amount).
- **Day 3:** Aggregate functions (COUNT, SUM, AVG, MAX, MIN), grouping data with GROUP BY.
    - **Task:** Calculate the average order value, the total number of orders, and the most expensive product sold.
- **Day 4:** Joining tables (INNER JOIN), understanding primary and foreign keys.
    - **Task:** Combine data from two tables (e.g., orders and customers) to retrieve customer information along with their order details.
- **Day 5:** LEFT JOIN, RIGHT JOIN, and UNION.
    - **Task:** Explore different types of joins to understand how they include or exclude data. Combine data from similar tables using UNION.
- **Day 6 & 7:** Review and Practice. Work on small coding challenges to solidify concepts.
    - **Task:** Complete online SQL quizzes or exercises (e.g., Khan Academy, SQLZoo) to reinforce learning.

**Week 2: Advanced SQL and Project Start**

- **Day 8:** Subqueries, using IN and EXISTS.
    - **Task:** Write a query that uses a subquery to find customers who have placed an order in the last month.
- **Day 9:** Working with Dates and Strings.
    - **Task:** Extract different parts of dates (e.g., month, year) and manipulate strings (e.g., concatenate first and last names).
- **Day 10:** Introduction to Database Design and Normalization.
    - **Task:** Design a simple database schema for a small business (e.g., an online store) with at least three tables.
- **Day 11:** Views and Stored Procedures.
    - **Task:** Create a view that shows a summary of sales data and a stored procedure that automates a common task.
- **Day 12 - 14:** **SQL Project:** Start working on a SQL project using a real-world dataset (e.g., from Kaggle). This project will involve:
    - **Task:** Data cleaning, transformation, and analysis using the SQL techniques learned so far. Aim for a project that can be showcased in your portfolio.

**Week 3: Introduction to DAX**

- **Day 15:** What is DAX? Understanding Power BI Desktop and its interface.
    - **Task:** Familiarize yourself with the Power BI Desktop environment, import a sample dataset, and explore the different views.
- **Day 16:** Calculated Columns vs. Measures. Writing basic DAX formulas.
    - **Task:** Create calculated columns to combine or transform data within a table (e.g., calculate the total price from quantity and unit price).
- **Day 17:** Working with Filters in DAX (FILTER, ALL, ALLEXCEPT).
    - **Task:** Write measures that calculate sales for specific product categories or time periods.
- **Day 18:** DAX Time Intelligence functions (TOTALYTD, SAMEPERIODLASTYEAR).
    - **Task:** Calculate year-to-date sales and compare current sales to the same period last year.
- **Day 19:** Introduction to CALCULATE function - the most powerful DAX function.
    - **Task:** Use CALCULATE to modify the filter context and create complex measures.
- **Day 20 & 21:** Review and Practice. Work on small DAX challenges using sample data.
    - **Task:** Complete online DAX exercises or tutorials to strengthen your understanding of the concepts.

**Week 4: Advanced DAX and Project**

- **Day 22:** DAX Iterator functions (SUMX, AVERAGEX).
    - **Task:** Use iterator functions to perform calculations row by row.
- **Day 23:** Working with Relationships in DAX.
    - **Task:** Create and manage relationships between tables in Power BI, understand how relationships affect DAX calculations.
- **Day 24:** DAX Variables and Context Transition.
    - **Task:** Use variables to simplify complex calculations and understand how to transition from row context to filter context.
- **Day 25:** DAX Table functions (FILTER, ADDCOLUMNS).
    - **Task:** Create virtual tables using DAX table functions to manipulate and analyze data.
- **Day 26 - 28:** **DAX Project:** Start working on a DAX project using the same dataset as your SQL project.
    - **Task:** Create measures to answer specific business questions, perform time series analysis, and derive insights from your data.

**Week 5: Power BI Visualization and Dashboarding**

- **Day 29:** Creating basic visualizations in Power BI (charts, tables, maps).
    - **Task:** Choose appropriate visualizations to represent your data effectively (e.g., bar charts for comparisons, line charts for trends).
- **Day 30:** Working with Slicers, Filters, and Drill-through.
    - **Task:** Add interactive elements to your reports to allow users to explore data and gain insights.
- **Day 31:** Designing interactive dashboards with multiple visualizations.
    - **Task:** Combine different visualizations into a cohesive dashboard that tells a story about your data.
- **Day 32:** Introduction to Power BI themes and formatting.
    - **Task:** Customize the look and feel of your dashboards to make them visually appealing and professional.
- **Day 33:** Publishing and sharing Power BI reports.
    - **Task:** Publish your dashboard to the Power BI service and share it with others.
- **Day 34 & 35:** **Portfolio Building:** Refine your SQL and DAX projects. Document your projects clearly, explaining your approach, techniques used, and insights gained.

**Week 6: Power BI Dashboard Project and Advanced Topics**

- **Day 36 - 38:** **Power BI Dashboard Project:** Build a comprehensive Power BI dashboard using your chosen dataset.
    - **Task:** Integrate your SQL and DAX skills to create a dynamic and insightful dashboard that showcases your data analysis abilities.
- **Day 39:** Introduction to Power Query for data transformation.
    - **Task:** Use Power Query to clean, transform, and prepare data before loading it into Power BI.
- **Day 40:** Exploring advanced DAX functions and techniques.
    - **Task:** Learn about more advanced DAX functions (e.g., RANKX, SWITCH) and how to optimize DAX performance.
- **Day 41 & 42:** Final Project Polish and Portfolio Completion:
    - **Task:** Add finishing touches to your Power BI dashboard, ensure your portfolio is well-presented and highlights your key skills.

**Important Considerations:**

- **Dataset:** Choose a dataset that interests you and aligns with your career goals. Kaggle, UCI Machine Learning Repository, and government websites are excellent sources.
- **Practice:** Consistent practice is key. Dedicate time each day to reinforce concepts and experiment with different techniques.
- **Resources:** Utilize online resources like Microsoft Learn, SQLBolt, and DAX.guide for additional learning and support.
- **Portfolio:** A strong portfolio is essential for showcasing your skills to potential employers. Ensure your projects are well-documented and demonstrate your analytical abilities.

This schedule provides a solid foundation in SQL, DAX, and Power BI. Remember to adapt it to your own pace and learning style. Good luck with your data analysis journey!
