# Personal Knowledge Vault & Operational Standards

## Canonical Storage Rules
- Personal Notes & Zettelkasten: `/workspace/notes/` (Host: `/data/notes/`)
- Daily Morning Briefs: `/workspace/notes/morning-briefs/[YYYY-MM-DD]-morning-brief.md`
- Audio Delivery: `/workspace/podcasts/Morning Brief/[YYYY-MM-DD]-morning-brief.mp3`
- Personal Documents: `/workspace/documents/` (Host: `/data/documents/personal/`)
- Ingestion Staging: `/workspace/staging/` (Host: `/data/downloads/staging/`)

## Writing Conventions
- Format daily briefs with strict frontmatter (`title`, `date`, `tags`).
- Action items must use markdown checklists: `- [ ] Task`.
- Zero outbound email dispatch. All drafts go to chat for human review.
