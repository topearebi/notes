## 3.1 Master Directory Structure
The server's entire operation is built around a portable, three-part folder structure located at `C:\server`. This strategy ensures that all essential data and configurations are centralised, simplifying backup, restoration, and migration.
The three core subfolders and their designated roles are:
- **`C:\server\config` (The Blueprints):** This directory exclusively contains the `docker-compose.yml` and `.env` files for every application stack. It represents the declarative state of all services.
- **`C:\server\appdata` (The Brains):** This directory stores all persistent data that applications need to function, including their internal databases, settings, and user-generated configurations. Each application has its own subdirectory here.
- **`C:\server\data` (The Library):** This directory is for all user-facing files that are managed by the services, such as documents, photos, media files, and Nextcloud user data.

### Docker Engine Setup
Docker is the core containerisation engine used to run all services on the server. The setup process is as follows:
1. **Install Docker Desktop:** Download and install the latest stable version of Docker Desktop for Windows from the official website. Ensure it is configured to use the WSL 2 based engine for optimal performance.
2. **Create Server Directory Structure:** A master directory is created to contain all persistent server data and configuration. This structure must be created before deploying any services.
